# 换机交接说明书（模板）

> 复制到项目里改：把下面的 `<占位>` 全部换成实际值。
> 目的：换电脑后，**你**或**接手的 AI** 照着这份文件就能恢复现场，不需要重新摸索。

---

## 一、这套是干什么的

<一句话说清：备份的是什么、给谁用。例如：备份本机的技能、PDCA 经验库、验收脚本和两层记忆，换机后一键恢复工作方式与过程资产。>

## 二、文件都在哪

| 类别 | 路径 | 说明 |
|---|---|---|
| 技能目录 | `<例如 <用户目录>/.workbuddy/skills>` | 每个技能一个子目录 |
| 经验库 | `<例如 <技能目录>/pdca-strict-delivery/qa/playbook.json>` | 复盘沉淀的经验条目 |
| 验收脚本 | `<例如 <技能目录>/pdca-strict-delivery/scripts>` | 检查器、引擎、护栏 |
| 用户级记忆 | `<例如 <用户目录>/.workbuddy/user-<id>-personal/MEMORY.md>` | 你的长期规矩 |
| 工作区记忆 | `<例如 <项目根>/.workbuddy/memory>` | 每日工作日志 + 项目长期笔记 |
| 快照包 | `<例如 <项目根>/过程资产/out>` | 每次备份产出一个 zip |
| 备份脚本 | `<例如 <项目根>/过程资产/backup.py>` | 打包入口 |
| 恢复脚本 | `<例如 <项目根>/过程资产/restore.py>` | 解包入口 |

## 三、每天怎么自动跑

| 项 | 值 |
|---|---|
| 计划任务名 | `<例如 过程资产备份>` |
| 触发时间 | <例如 每天 22:40> |
| 执行命令 | `<例如 python <项目根>/过程资产/backup.py --config ...>` |
| 产物落点 | `<例如 <项目根>/过程资产/out/assets-YYYYMMDD-HHMMSS.zip>` |
| 云端副本 | `<例如 阿里云盘 /同步目录名>` |
| 保留策略 | <例如 保留最近 10 个包，旧的移到 _old> |

**运行期零 token**：脚本是纯本地 Python，不调任何大模型，不需要 Agent 在线。

## 四、换机三步

1. **装环境**：装 Python（<版本>）、装阿里云盘客户端并登录同一账号、装 WorkBuddy。
2. **恢复文件**：从云端下载最新快照包 → 解压到目标位置 → 或直接跑恢复脚本：
   ```
   <例如 python <项目根>/过程资产/restore.py --package <包路径> --target <用户目录>/.workbuddy>
   ```
   恢复脚本会逐项校验 sha256 并打印恢复清单。
3. **验证**：跑一次自检，确认技能被识别、门禁能跑：
   ```
   <例如 python <技能目录>/scripts/pycompile_all.py>
   ```

## 五、出故障怎么办

| 现象 | 原因 | 处理 |
|---|---|---|
| 计划任务没跑 | 关机/休眠时错过 | 手动跑一次 backup.py；或把触发时间改到开机后 |
| 包没出现在云端 | 云盘客户端未登录或同步盘未挂载 | 打开阿里云盘客户端确认已登录；手动把 out 里的 zip 拖进去 |
| 恢复后技能不认 | 目录层级不对 | 恢复脚本的 --target 要指到 .workbuddy 那一层，不是 skills 本身 |
| 脚本报 ModuleNotFound | Python 版本/路径不对 | 用绝对路径调用 python.exe，别用 `python` |
| 中文文件名乱码 | 控制台编码 | 设 `PYTHONUTF8=1`，或用 `-X utf8` |

## 六、给接手的 AI 的指令

> 把下面这段原样发给新机器上的 AI，它就知道从哪读、按什么顺序读、哪些不能动。

```
接手本机工作，请先读以下文件（按顺序）：
1. <项目根>/过程资产/说明.md        ← 本文件，先读这里
2. <用户级记忆路径>                    ← 我的长期规矩（含开工授权约定）
3. <工作区记忆路径>/MEMORY.md          ← 项目长期笔记
4. <技能目录>/pdca-strict-delivery/SKILL.md  ← 交付方法论
5. <技能目录>/pdca-strict-delivery/qa/playbook.json  ← 复盘经验库

规矩：
- 只有我明确下达开工指令才动手；其他表述一律当讨论，只分析不改文件。
- 改任何文件前先读，别凭印象写；改完核对无丢失无乱码。
- 数据查不到就写"未获取"，绝不编造。
- 本地过程资产不得自动上传到云端，只有本备份脚本是允许的例外。
- 关键数据改动须有凭据，无凭据不改动。
```

## 红线

- 备份包**不含**：隐私截图、账户凭证、密钥文件、`.credentials.yaml`、敏感明细数字。
- 包内文本按脱敏规则处理：金额 → `[金额]`，长数字账号 → `[账号]`，长串密钥 → `[密钥]`。
- 备份脚本是唯一允许把过程资产传出本机的通道；其它任何操作不得自动上传。
